# gestion_web

Sistema de gestión web desarrollado en Django.

## Tecnologías
- Python 3.x
- Django 5.x
- SQLite (desarrollo)
- MySQL (producción / cPanel)
- HTML + Django Templates
- Git (ramas: desarrollo, master)

## Instalación rápida
```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
